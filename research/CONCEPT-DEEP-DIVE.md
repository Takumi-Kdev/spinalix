## 1. あなたの案の核（私の理解）

> Obsidianのような「手動リンクされた静的なメモの集合」ではなく、
> **人間の断片的な感情・急に思い浮かぶ要素を、記憶と感情の中から生成し続ける「完全記憶体」**。
> 単なるデータの蓄積と連結では生まれない概念を、新しい考え方で生み出す。

私の解釈: **これは「記憶にできるAI」ではなく「記憶をするAI」である。**
- 検索は「問い」を必要とする。人間の想起は「問い」を必要としない。
- 既存AIメモリーは「保存と検索」。この案の本質は「**システムが先に考え、先に話す**」。

## 3. プロダクト定義（研ぎ澄まし後）

### 一文で
> **断片（感情つき）を貯めるだけで、AIが記憶回路を組み、あなたの中から「ふとした想起」を生成し、決断や創作という具体的な成果物に変える、ローカル完結の思考脳。**

### このAIで「今までできなかったこと」（審査に直結）
1. **問いがなくても記憶が使われる** — システム主導の想起カード（毎朝/毎晩届く）
2. **自分の矛盾に気づける** — 過去の自分の言葉との食い違いを、AIが忖度せず指摘する
3. **AIの答えに納得できる** — 全ての想起・洞察に**出典（いつ・どの断片）**が付く。ブラックボックス禁止
4. **記憶が自分の手元にある** — PC常駐・ローカル完結。感情データを企業に渡さない

### コアループ（使い方→結果までを極限まで完結に）
```
 ① 捕獲 (5秒)   音声/一行 + 気分スライダー1つ。整理・フォルダ・リンクは一切不要
      ↓ 自動（人間の作業ゼロ）
 ② 回路          AIが感情ベクトル・人物・テーマを抽出し、グラフに自動接続（Obsidianの手動リンクの逆）
      ↓ 自動（毎日届く）
 ③ 想起          遠い記憶×最近の感情の交差から「ふとカード」が生まれる。矛盾の指摘付き
      ↓ 必要な瞬間に
 ④ 目的モード    問い/決断/創作テーマを入力 → 「思考結晶」= 引用付き根拠 + 感情の流れ + 生成洞察
      ↓ 人間の感情で選ぶ
 ⑤ 選択          「これは私だ / 違う」→ 選ばれた想起だけが回路に定着。AIがあなたの感覚を学習
```

### Obsidianとの違い（審査員に聞かれたら）
| | Obsidian等 | 本プロダクト |
|---|---|---|
| 構造化 | 人間が手動でリンク | AIが自動で回路化 |
| 感情 | ただの文字列 | **第一級データ**（valence/arousal、感情の時間変化） |
| 動き | 検索するまで静的 | **システムが先に想起を生成する** |
| 出力 | ノート | 思考結晶（引用・矛盾・洞察） |
| データ主権 | ローカル | ローカル（さらにMarkdown/Obsidian形式でエクスポート可能） |

### 倫理設計（あなたの「人間の倫理観を壊さない」を実装に落とす）
- **捏造しない**: 生成された想起は必ず原断片にリンク。出典のない文は出さない
- **忖度しない**: 同意と励ましではなく、矛盾と見落としを提示する（anti-sycophancy）
- **依存させない**: 通知は1日2回まで、オフ可能。「もっと使わせる」設計をしない
- **持たせない**: ローカル完結。E2E暗号化なしにクラウドへ感情データを送らない

## 4. PC常駐 + スマホのアーキテクチャ

```
[Mac: 常駐する「脳」]                    [スマホ: PWA]
 ・ローカルサーバ (Node)                  ・同じ画面が動く（PWAとしてインストール可）
 ・SQLite（断片・回路・感情）             ・LAN接続: 画面のQRコードを読むだけで接続
 ・埋め込み + 生成（Gemini無料枠）        ・スマホ単体モード: 端末内DBで捕獲/閲覧は完全オフライン
 ・APIキーは本体にのみ保存（端末に出さない）
        ↑ LAN / 将来: E2E暗号化同期
[審査員向け] 同一アプリをクラウドにもデプロイ（デモデータ同梱・キー不要で全機能が動く）
```

## 6. 実装スコープ（6時間・削り込み済み）

**MUST（これだけは動かす）**
- 断片追加（テキスト + 気分スライダー + 音声入力は可能なら）
- 自動リンクと回路ビュー（force-directed graph、想起時に該当パスが光る）
- 想起生成（Gemini無料枠 + APIなしでも動く定型フォールバック）
- 目的モード → 思考結晶（引用付き）
- 採否フィードバック
- 8ヶ月分のデモペルソナ記憶（60〜80断片）
- クラウドデモ（キー不要で審査員が触れる）

**NICE（時間が余ったら）**
- QRコードでスマホ接続の実演 / Obsidian形式エクスポート / 年間製本プレビュー / スマホ単体オフライン

## 7. リスク
| リスク | 対策 |
|---|---|
| 6時間で実装量が重い | 私がコードをほぼ全部生成。UIは1画面完結・機能は絞る |

| 審査員が「Rosebud等と同じでは?」 | 「応答型」ではなく「**開始型（システムが先に話す）**」＋出典必須＋矛盾指摘＋ローカルを強調 |
