## エンジン（v2）— 決定論的・端末内・検証可能

### 1. 活性化 `src/lib/activation.ts`

- 基礎活性 = **感情強度 × 忘却曲線（半減期180日）× 参照回数**（recallリンク数）＋出典種別。
- **プライミング**: 直近の断片・強い感情の断片・サイクルごとに回る高活性記憶を「今のあなた」の種にする。
- **拡散活性化**: 種からリンクを2ホップ伝播（種類別の伝導率: recall 1.0 / tension 0.85 / echo 0.8 / similar 0.5 / person 0.4 / theme 0.3、ホップ減衰0.55）。

### 2. 回路 `src/lib/engine.ts`

断片の全ペア（O(n²)、100断片級では十分軽量）から6種のリンクを生成:
`similar`（文字バイグラム×感情類似）/ `echo`（同じ感情・21日以上・言葉は遠い）/ `tension`（同テーマ・valenceが0.85以上反対）/ `recall`（自己引用: 「」句が過去断片に実在）/ `theme` / `person`。
ノード×種類の上限 → ノード上位8本。「少数精鋭でないと矛盾はノイズになる」という設計判断。

### 3. 分析 `src/lib/analysis.ts`

- **テーマの弧**: 前半/後半のvalence比較で rising/falling/flat。
- **開いた輪**: 意志語（やりたい/行きたい/始めたい…）と行動語（始めた/申し込/予約/出した…）の差と静穏期間から、*言ったのに、やっていないこと*を検出。
- **人プロフィール**（言及数・valenceの推移）、**問い**（問いの形のまま残った断片）、**沈黙したテーマ**。

### 4. 思考歩行 `src/lib/walk.ts`

プライミング種からビーム探索（幅5・最大2〜3ホップ）。5つの歩き方:

| モード | 何を探すか | リンク優遇 |
|---|---|---|
| resonance（共鳴） | 過去の自分の言葉が今に効いている道 | recall 1.6 / echo 1.25 |
| contrast（対照） | 向きが変わった道 | tension 1.7 |
| dwell（反すう） | 同じ感情が続いている道 | echo 1.55 |
| arc（軌跡） | 一本の道（最大3ホップ） | recall/tension/echo |
| leap（跳躍） | 言葉は無関係で、感情だけ同じ | 低語彙重複を優遇 |

時間の往復（ジグザグ）は減点。同じペアは二度使わない。直近の想起で使ったノードは冷ます。**サイクルごとに歩き方をローテーション**。

### 5. 言語化 `src/lib/render.ts`

- **keyClause**: 断片から「いちばん強い一節」を取り出す（内側の引用は呼び戻しとして減点、意志語・感情語・長さ・位置で採点。引用外分割で「」の中は切らない）。
- モードごとの語り口（2〜3ホップの型）で、**引用は断片から、接続だけをエンジンが与える**。
- **思考の足跡**（起点→拡散→跳躍）を必ず生成し、UIで展開できる。

### 6. 検証 `src/lib/verify.ts` と API文体モード `src/lib/apiBrain.ts`

- APIに渡すのは〈思考状態〉のみ（道筋・断片・感情・エンジンの下書き・制約）。
- システムプロンプトで「あなたは文体家。考えない。足さない」と明示。
- 返答を **verify**: ①全引用が原断片に実在 ②出典にない日付の禁止 ③励まし・助言の決まり文句の禁止 ④160字以内。
- 失敗→1回だけ再試行→それでも失敗ならローカル文。**AI文体の思考はUIで「AI文体・検証済」と表示**。

## UI

- **ホーム**（想起と採否）/ **回路**（d3-zoom・ドラッグ・発火アニメ・ホバー・フォーカス）/ **流れ**（感情の川: 棒=断片、線=月次valence）/ **思考**（自立思考の記録・足跡の展開）/ **目的**（思考結晶）。
- 幾何学（28pxグリッド・ヘアライン・monoラベル）＋感情グラデーション（断片の感情ベクトルから生成: `design.ts`）。
- 検索・感情フィルタ・テーマフィルタ（サイドバー）→ 回路/流れに即時反映。

## テスト（17件）

- 仕込み済みの自己引用（心臓がうるさい）・矛盾（諦め↔決断）が実際に検出されること
- デモの筋書き（1件目=自己引用、2件目=矛盾、7件以内に諦め↔決断が出ること）
- 出典の実在・決定論性・ペア再利用の禁止・思考結晶の根拠
- 感情語彙の推定（正/負）

## 主要な技術判断

- **外部AI APIを使わない（通常時）**: 審査員がキーなしで全機能を試せる。APIは任意の「文体」のみで、検証層が記憶の外を語ることを許さない。
- **純関数＋決定論**: 動画の再撮影でも同じ想起が出る。テストが仕様になる。
- **Canvas描画**: 100断片・300リンクでも60fps。d3-zoom/dragで滑らかな操作。
- **相対パスビルド**: GitHub Pages / Electron / LAN配信のすべてで同じビルドが動く。
