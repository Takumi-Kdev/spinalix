# 制限（正直な開示）

Spinalix の「できないこと」を、誇張なく列挙します。

## エンジンについて

- **想起の文章は「抽出＋接続」方式です。** あなたの断片から一節を抽出し、道筋（起点→拡散→跳躍）を文につなぐもので、LLMによる自由な文章生成ではありません（決定論・APIキー不要とのトレードオフ）。文体の滑らかさはLLMに劣ります。API文体モードを使うと文章は整いますが、**内容はエンジンの思考のまま**です（それが設計意図です）。
- **回路は全ペアの比較（O(n²)）です。** 現在は数百断片まで快適に動きますが、1万断片規模ではブロック分割・近似最近傍への差し替えが必要です（設計は純関数なので差し替えは局所）。
- **感情推定は辞書ベース＋手動補正です。** 皮肉・比喩・文脈の複雑な感情は取りこぼします。心理学的な「正確な計測器」ではありません。
- **「矛盾」は検出されたものだけです。** 見逃しはありますし、解釈が浅い矛盾を提示することもあります。「矛盾」は評価ではなく、事実の提示です。
- **開いた輪（言ったのにやっていない）は語彙パターンに依存します。** 「やりたい」等の表現を拾うため、表現次第で検出漏れがあります。

## アプリ・同期について

- **配布アプリはコード署名していません。** 初回は「右クリック → 開く」が必要です（macOSのGatekeeper）。
- **同期は最終更新優先（last-write-wins）です。** 複数端末で同時編集すると、片方の変更が失われる可能性があります。E2E暗号化同期は未実装（同一LAN内のみ）。
- **LANサーバーに認証はありません。** 同一LAN内での利用を前提としています。LANの外に公開する場合は別途対策が必要です。
- **Obsidian取り込みは簡易パーサです。** frontmatter/日付/タグの基本形のみ対応し、複雑な構造（Dataviewクエリ等）は解釈しません。

## API文体モードについて

- **APIキー未設定でも全機能が動きます。** API文体モードは文章の質のための任意機能です。
- **検証は機械的な検査**（引用の実在・日付の捏造・決まり文句・長さ）であり、意味の完全な一致までは保証しません。検証に落ちた出力は破棄され、ローカルの文が使われます。
- キーは **localStorage にのみ** 保存され、brain.json や他端末には同期されません。

## デモデータについて

- ライブデモには**8ヶ月分のサンプル記憶**（架空ペルソナ「ハルカ」の断片 + 作者本人の実体験の一部を匿名化して混在）が同梱されています。実在の人物・団体との関係はありません。
- デモのデータは2026年2月〜10月です。それ以降に開くと、想起の日付が実際より過去に表示されることがあります。

## 健康・医療について

- Spinalixは**医療・診断・治療を目的としたものではありません。** つらい状態が続く場合は専門家に相談してください。
