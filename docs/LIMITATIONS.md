# 制限（正直な開示）

Spinalix の「できないこと」を、誇張なく列挙します。

## プロダクトについて

- **想起の文章は生成テンプレートによる合成です。** LLMによる自由文生成は行っていません（外部APIキー不要で誰でも動かせることとのトレードオフ）。合成文は必ず実在の断片の引用と日付に接地しますが、文学的品質はLLMに劣ります。LLMを接続する拡張点（Generatorインターフェース）は設計上分離済みです。
- **感情推定は辞書ベースです。** 日本語の語彙パターン + 手動補正で推定しており、皮肉・比喩・文脈の複雑な感情は取りこぼします。心理学的小規模でも「正確な感情計測器」ではありません。
- **意味的類似は文字バイグラム + 感情ベクトルによる近似です。** 埋め込みモデルによる深い意味理解ではありません（端末内埋め込みモデルへの差し替えは将来課題）。
- **「矛盾」はリンクとして検出されたものだけです。** 検出漏れ（テーマタグが無い断片など）はあります。逆に、断片のタイミングによっては解釈が浅い矛盾を提示することがあります。
- **同期は最終更新優先（last-write-wins）です。** 複数端末で同時編集すると、片方の変更が失われる可能性があります。E2E暗号化同期は未実装（LAN内のみ）。
- **認証機能はありません。** サーバーは同一LAN内での利用を前提としており、LANの外に公開する場合は別途対策が必要です。

## デモデータについて

- ライブデモには**8ヶ月分のサンプル記憶**（架空ペルソナ「ハルカ」の断片 + 作者本人の実体験の一部を匿名化して混在）が同梱されています。実在の人物・団体との関係はありません。
- デモの「今日」は2026年10月15日です。それ以降に開くと、生成される想起の日付表示が実際より過去に見えることがあります（記憶データが10月14日までのため）。

## 健康・医療について

- Spinalixは**医療・診断・治療を目的としたものではありません。** 感情の記録と想起の提示は、自己理解のための道具です。つらい状態が続く場合は専門家に相談してください。
- 「矛盾」の指摘は、あなたを否定するものではありません。事実の提示であって、評価ではありません。
