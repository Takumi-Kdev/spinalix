# Devpost 提出文 v2（コピペ用）

## 名称
Spinalix

## タグライン（200字以内）
断片（感情つきの一行）から、記憶エンジンが回路を組み、思考を歩いて「ふと思い浮かぶ思考」を生成する、ローカル完結の思考脳。思考はエンジンが行い、AIは文体だけを借りる——検証層が記憶の外を語ることを許しません。

## Inspiration

メモは貯まるのに、二度と読み返されない。AIに考えさせると、平均的な答えが返ってくる。
問題は、記憶が足りないことではなく、**自分の記憶が使われないこと**でした。

既存の「AIメモリー」は保存と検索です。人間の想起は、問いを必要としない。それならば——**システムの側から思考が生まれる記憶**を作れないか。Spinalixはそこから始まりました。

## What it does

- **想起の生成**: 感情つきの断片から、拡散活性化（今温まっている記憶）→ 記憶回路の歩行（ビーム探索）で想起を生成。自己引用・矛盾・反響・軌跡・跳躍・開いた輪・問いの7種類。
- **思考の足跡**: すべての想起に「起点→拡散→跳躍」を表示。出典のない文は生まれません。
- **自立思考モード**: アプリを開いている間、24秒ごとに自律的に記憶を歩いて考えます（「深く考える」で即時5サイクル）。
- **矛盾と開いた輪の指摘**: 「5月のあなたは諦めたほうがいいと言った。10月のあなたは——明日、出す。」忖度しません。
- **思考結晶（目的モード）**: 「留学に行くべきか」→ 出典つきの想起・感情の弧・洞察・矛盾・次の一歩。
- **デスクトップアプリ**: Macのメニューバーに常駐し、**⌥Spaceでどこからでも記録**。記憶はローカルのJSONのみ。
- **Obsidian取り込み**: Vault（フォルダ）を選ぶと、Markdownが断片として回路に組み込まれます。
- **API文体モード（新しい概念）**: **AIに考えさせません。** エンジンの〈思考状態〉だけを渡し、LLMは文体を整えるだけ。引用の実在・日付の捏造・ありきたりな励ましを検証し、違反した出力は破棄してローカル文に戻します。

## How we built it

- TypeScript + React + Vite + Tailwind / d3-force + d3-zoom / zustand / Electron
- エンジンは純関数・決定論的（`activation.ts` 拡散活性化 / `engine.ts` 6種の回路 / `analysis.ts` 開いた輪・テーマの弧 / `walk.ts` 思考歩行 / `render.ts` 抽出＋接続の言語化 / `verify.ts` 門番）
- Mac常駐サーバーは Node 標準ライブラリのみ（依存ゼロ）。Electronアプリに内蔵し、`~/Library/Application Support/spinalix/brain.json` に保存。静的環境では localStorage に自動フォールバック
- テスト17件: 仕込み済みの自己引用・矛盾が実際に検出されること、デモの筋書き、決定論性、出典の実在など

## Challenges we ran into

1. **「読み物」ではなく「回路」にする難しさ**: 初期の実装はリンクが多すぎて矛盾がノイズになりました。ノード×種類の上限と「少数精鋭」設計に変えて解決。
2. **生成の品質**: LLMに任せず、あなたの断片から一節を抽出して道筋を文につなぐ方式に。引用はあなたの言葉のまま、接続と視点だけをエンジンが与えます。
3. **APIの位置づけ**: 「AIに考えさせたら負け」という設計制約を、〈思考状態〉の受け渡し＋検証層という形で実装しました。AIの出力は、記憶にないことを言った瞬間に破棄されます。

## Accomplishments that we're proud of

- 8ヶ月分の記憶（64断片・265回路）から、仕込んだ自己引用と矛盾を**エンジンが実際に発見**することをテストで証明
- 外部AI APIなしで、想起・自立思考・思考結晶が完全に動作（審査員がキーなしで試せる）
- ダウンロードして普通に使える**Macアプリ**（メニューバー常駐 + ⌥Space捕獲）
- 「AIに考えさせない」ことを構造で保証したAPIモード

## What we learned

- 記憶の本質は保存ではなく**再結合と選択**であること
- 感情を第一級データにすると、検索では出てこないつながり（遠い時期の同じ感情、向きの違う発言、開いた輪）が見つかること
- 決定論的なエンジンでも、入力と採否次第で、驚くほど個人的な出力になること
