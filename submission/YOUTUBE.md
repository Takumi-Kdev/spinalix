## 説明欄

```
Spinalix は、断片（感情つきの一行）を貯めると記憶の回路を自動で組み、あなたの中から「ふと思い浮かぶ思考」を生成する、ローカル完結の思考脳です。

・思考はエンジンが決定論的に行い、AIには文体だけを許します。引用の実在・日付の捏造・ありきたりな励ましは検証層が棄却します。
・すべての想起には、出典と「思考の足跡」（起点 → 拡散 → 跳躍 → 解剖）が付きます。捏造しません。
・自立思考モード、矛盾と開いた輪の指摘、目的モードの思考結晶、Obsidianの取り込み。
・Macアプリ（メニューバー常駐・⌥Spaceで記録）＋スマホ接続。記憶はローカルのJSONだけに保存されます。

デモの記憶は8ヶ月分のサンプル（架空のペルソナ＋作者本人の実体験）です。ナレーションは英語の合成音声、字幕は自動生成です。

プロダクトページ: https://takumi-kdev.github.io/spinalix/
Macアプリ: https://github.com/Takumi-Kdev/spinalix/releases/latest
GitHub: https://github.com/Takumi-Kdev/spinalix

Built by Takumi Kawai. Next Founders Hackathon 2026.
```
